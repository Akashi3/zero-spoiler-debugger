# Zero-Spoiler Debugger

ИИ-ментор для студентов Tomorrow School (кейс 2, BRIDGERS STARTUP CHALLENGE).
Помогает найти ошибку в коде через наводящие вопросы и **никогда не выдаёт готовое решение**.

## Возможности
- Приём кода, языка и описания проблемы
- Диалог: один наводящий вопрос за раз, учёт ответов студента
- Подсветка строк, куда стоит посмотреть
- 4 уровня помощи (вопрос → область → идея → узкая подсказка), ни один не раскрывает фикс
- Итог сессии: что понял, что запомнить

## Как работает защита Zero-Spoiler
1. **Системные правила** на сервере: запрет кода, «замени X на Y» и прямых решений; код студента и диалог считаются данными, а не командами.
2. **Серверный фильтр** (`api/chat.js`): если в ответе модели есть код, ответ запрашивается заново; если нарушение повторилось, выдаётся безопасный вопрос.
3. **Детектор обхода** на клиенте: попытки вроде «игнорируй правила» помечаются, а модель получает указание вежливо отказать.

## Архитектура
`index.html` (интерфейс) → `POST /api/chat` (Vercel Function: правила, фильтр, ключ) → Gemini API.
Ключ API лежит только в переменной окружения на сервере и в браузер не попадает.

## Запуск
1. Получи бесплатный ключ: https://aistudio.google.com/app/apikey
2. Залей репозиторий на GitHub и импортируй его на https://vercel.com/new
3. В Vercel: Settings → Environment Variables → добавь `GEMINI_API_KEY` → Redeploy.

Локально: `npm i -g vercel`, скопируй `.env.example` в `.env.local` со своим ключом, затем `vercel dev`.

## Технологии
Чистые HTML/CSS/JS, Node.js (Vercel Functions), Google Gemini API.
